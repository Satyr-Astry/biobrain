## 六、关键技术事实（少走弯路）

1. **语义模型来源**：`hf-mirror.com`（HF 直连被墙），`HF_ENDPOINT` 环境变量控制
2. **稀疏点火**：感觉端只点亮 top-50%，否则语义区分度归零
3. **传播需要时间**：激活扩散要跑够 tick（5步0.02 → 15步0.91），这是**仿生特性不是bug**
4. **在线可塑用 pending 缓存**：只影响未来，保证因果性
5. **自评信号禁止入缓冲**：防自噬（`source` 必须是 oracle/user_action/outcome）
6. **REM 产物只入候选库**：不直接合并入 base（防幻觉污染）
7. **合并需独占**：分片挂起算"活动计算"，不可合并

### ★关键转折：从「网络学习」改为「向 LLM 学习」

**主人的决策**（正确）：不要浪费时间在互联网上学习，直接向 LLM 学。

**实测对比**：

| 指标 | 网络学习 | LLM 学习 |
|---|---|---|
| 每主题耗时 | 3-5 分钟 | **73-85 秒** |
| 入库率 | 0-30% | **100%** |
| 内容质量 | 65% 是垃圾 | 300-800 字实质内容 |
| 典型错误 | 搜"KV缓存"学到"千伏"、搜"扩散模型"学到"分子扩散" | 无 |

**新模块**：
- `llm_distiller.py` —— LLM 蒸馏器（大纲 → 讲解 → 自检 → 入库）
- `batch_learn.py` —— 批量学习（12 主题预设，进度可续）
- `clean_memory.py` —— 记忆库质量清理（按来源+长度+垃圾模式打分）

**关键设计**：
- 教学视角 prompt（教材式，非聊天式）
- **自检机制**：LLM 检查自己的错误，存疑降权 50%
- 置信度提取（让它标注把握程度）
- 来源质量分级：`ai_llm`(0.9) > `web_wiki`(0.6) > `web_search`(0.3)

**记忆库清理结果**：52 条 → 18 条（剔除 34 条垃圾，垃圾率 65%）
—— 实证了网络学习的问题
