# 流式数据架构愿景与落地路线（v1.0）

> 落笔：2026-09-19
> 来源：主人提出的完整架构设想（流数据输入 → 神经处理 → 流数据输出）
> 状态：**架构愿景 + 落地对照**。已写入 `总架构书.md` §1.5。
> **每条都标注了项目现状（实测）与差距**，不是空想。

---

## 0. 主人设想的完整链路（原文整理）

```
① 输入转化
   传感器 / 视频流 / 电压数据
        ↓ 解析
   矩阵流（矩阵序列）
        ↓ 传播
② 神经处理（低成本跑通的三支柱）
   · 时空间梯度稀疏发散
   · 多层神经元群组
   · 群组 KV 缓存归一化
        ↓
③ 自学习机制
   · 检查"对齐度" → 判断输入陌生程度
   · 反向传播（按陌生度调节）
        ↓
④ 输出转化
   神经活跃 → 输出端口持续传播矩阵流
        ↓ 拟合达阈值
   反向解析 → LLM / 生图模型 / 运动数据（如电压）
```

**核心洞察**：**整个项目应该是"矩阵流的翻译器"** ——
把任意模态的流数据翻译成神经矩阵流，再反向翻译回去。

## 2. 关键澄清：设想的"反向传播"与 NORM-3 的关系

### 2.1 主人的"反向传播"可能指什么

从上下文（"通过检查神经网络对齐度判断输入数据陌生程度，反向传播"）看，
**主人说的不是传统 BP**，而是**"用对齐误差反向调节"** ——
这在神经科学里对应 **三因子学习规则**（误差/奖励调制局部可塑）。

### 2.2 三种可能的实现路径

| 路径 | 是否符合 NORM-3 | 可行性 | 说明 |
|---|---|---|---|
| **A. 传统 BP** | ❌ 违反（需停机训练 + 破坏因果） | 需引入 torch | 会推翻项目定位 |
| **B. 三因子局部规则** | ✅ **符合**（在线，无独立阶段） | **可立即实施** | `Δw = η · e(t) · M(t)`，M(t) 来自"对齐误差" |
| **C. 对齐误差作调制信号** | ✅ 符合 | 可实施 | 对齐度低 → 加强学习；对齐度高 → 减弱 |

**结论**：**用 B/C，不用 A** ——
**"反向传播"的意图（用误差指导学习）完全可以由三因子规则实现**，
且**不需要反向传播的计算图**（O(1) 内存 vs BPTT 的 O(T)）。

### 2.3 新增缺陷记录

| # | 缺陷 | 影响 | 优先级 |
|---|---|---|---|
| **P-STREAM-1** | 输入侧只支持文本（视觉是随机投影） | 无法接传感器/视频流 | P2 |
| **P-STREAM-2** | 扩散无梯度/时空间结构（只有标量增益） | "时空间梯度稀疏发散"未实现 | P2 |
| **P-STREAM-3** | `novelty = std(assoc)` 是简化版，非真对齐度 | 陌生度判断不可靠 | **P1** |
| **P-STREAM-4** | 输出端只支持离散符号（无矩阵流） | 无法驱动生图/电压输出 | P2 |
| **P-STREAM-5** | 无"对齐度→学习强度"的调制通路 | 自学习机制不闭环 | **P1** |

## 3. 落地路线（分阶段，按依赖排序）

### 阶段 A：**打通"矩阵流"的基础设施**（前置）

```
A1. 定义 MatrixStream 抽象（输入/输出统一）
    · 输入：任意 shape 的时间序列 → 统一为 (T, D) 矩阵流
    · 输出：神经激活 → (T, D) 矩阵流
    · 这是整个设想的地基

A2. SensoryPort 泛化
    · 现在：SensoryPort(modality, ids, dim) —— 硬编码文本/视觉
    · 目标：SensoryPort(modality, ids, dim, decoder=...) —— 可插拔解码器
    · 文本解码器 = bge（已有）| 视觉解码器 = 待接 | 传感器解码器 = 归一化即可

A3. MotorPort 泛化
    · 现在：MotorPort("language", ids, threshold)
    · 目标：MotorPort(modality, ids, encoder=...) —— 可插拔编码器
    · 语言编码器 = 待接 LLM | 电压编码器 = 反归一化
```

### 阶段 B：**对齐度系统**（治 P-STREAM-3/5）

```
B1. 真对齐度（替代 novelty=std）
    · 对齐度 = 当前输入编码 与 记忆库中最相似经验的相似度
    · 或 = 预测误差（用 RecallEngine 的检索结果做预测）

B2. 对齐度 → 学习调制
    · 对齐度低（陌生）→ 加强学习（M(t) 大）
    · 对齐度高（熟悉）→ 减弱学习（M(t) 小）
    · 用 ALG-21（三因子 neuromod）承载
```

### 阶段 C：**时空间梯度稀疏发散**（治 P-STREAM-2）

```
C1. 给 SPREAD 加方向性/梯度
    · 现在：SPREAD_GAIN × dynamics（标量扩散）
    · 目标：沿"梯度方向"扩散（用 role 基向量的差值作梯度）
C2. 时空间结构
    · 空间：按 tier + 距离衰减
    · 时间：按 tick 累积（快/慢时间尺度分离，ALG-22）
```

### 阶段 D：**输出对接**（治 P-STREAM-4）

```
D1. 矩阵流拟合（判断是否达阈值）
D2. 反向解析器（pluggable）
    · → LLM（BIO_GEN_BACKEND_URL 已有钩子）
    · → 生图模型（ComfyUI API，主人本机已有）
    · → 电压/运动数据（反归一化）
```

## 6. 一句话总结

> **主人的设想是"把项目做成矩阵流的双向翻译器"** ——
> **输入侧**：任意模态 → 矩阵流 → 神经
> **输出侧**：神经 → 矩阵流 → 任意模态
>
> **项目现状**：链路**框架已在**（SensoryPort/MotorPort/四级组织/KV），
> **但每一环都是半成品**（文本硬编码、视觉是随机投影、无梯度扩散、陌生度是简化版、输出只支持离散符号）。
>
> **最关键的两个缺口**：
> ① **MatrixStream 抽象**（整个设想的地基，现在没有）
> ② **对齐度→学习的调制通路**（自学习不闭环）
>
> **"反向传播"用三因子规则替代**（符合 NORM-3，且不需计算图）。
