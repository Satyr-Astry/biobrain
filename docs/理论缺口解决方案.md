# 缺口 1：多时间尺度耦合

## 1.1 问题本质
本方案混着 5 个时间尺度，却没说清它们的耦合关系：
| 尺度 | 机制 | 典型周期 |
|---|---|---|
| τ₁ | 突触可塑（Hebbian） | 毫秒（单 tick） |
| τ₂ | 激活衰减 | 秒（decay per tick） |
| τ₃ | 经验积累 | 秒~分钟 |
| τ₄ | 睡眠合并（NREM/REM） | 分钟~小时 |
| τ₅ | 神经发生 | 天~周 |

**风险**：τ₁ 太快→噪声被当信号；τ₂ 太快→经验来不及积累；τ₄ 太频繁→不稳定。

## 1.2 实证坐标（关键论文）
- **《Learning at Multiple Timescales》(NeurIPS)**：提出**每个权重 = 多个"子权重"之和，各自在不同时间尺度上独立学习**。快权重是其特例。
- **核心定理**：**"假设时间尺度之间存在耦合的复杂模型，可通过重参数化消除耦合，等价于多尺度学习器"** —— 这意味着**我们不需要显式建模耦合，让各尺度独立学习即可**！
- 另一发现：**momentum 学习等价于"负学习率的快权重"**。
- **《Multi-timescale RL in the brain》(Nature 系)**：大脑**多巴胺神经元编码多个时间尺度的预测**（不同折扣因子），"多时间尺度系统能在逆拉普拉斯空间编码所有未来时刻的期望奖励"。
- **三因子可塑性（2512.09366）**：`Δw = eligibility_trace × reward_prediction_error` —— **资格痕迹(快) × 奖励预测误差(慢)** 正是"快慢耦合"的生物实现。

## 1.3 工程方案：**子权重叠加 + 资格痕迹**

### (A) 每个权重 = 多个子权重（直接采用 NeurIPS 定理）
```python
@dataclass
class MultiScaleWeight:
    subweights: list[Tensor]        # [w_fast, w_mid, w_slow] 各自独立学习
    etas: list[float]               # [0.1, 0.02, 0.001]     各自学习率
    decay: list[float]              # [0.5, 0.9, 0.999]      各自衰减
    def value(self): return sum(self.subweights)   # 有效权重 = 求和
```
**好处**：**不需要显式建模尺度耦合**——定理保证"耦合模型 ≡ 独立子权重之和"。

### (B) 三因子资格痕迹（解决"延迟奖励怎么归因"）
```python
# 快: 资格痕迹(eligibility trace) — 记录"最近谁一起活跃"
e_t = lambda_e * e_{t-1} + hebbian(pre_t, post_t)
# 慢: 奖励预测误差 — 事后才知道好坏
rpe = actual_reward - expected_reward
# 加权: 快痕迹 × 慢信号 → 更新
Δw = eta * e_t * rpe        # ★时间尺度耦合就发生在这里
```
**这是关键**：**资格痕迹(快)负责"记住刚才发生了什么"，奖励(慢)负责"事后告诉它对不对"**——两者相乘，就实现了**跨时间尺度的信用分配**。

### (C) 尺度参数表
| 子权重 | 学习率 | 衰减 | 作用 |
|---|---|---|---|
| w_fast | 0.1 | 0.5 | 快速适应（当前任务） |
| w_mid | 0.02 | 0.9 | 中期记忆（本次会话） |
| w_slow | 0.001 | 0.999 | 长期知识（合并进 base） |

### 1.4 验收标准
- **MUST**：三个尺度可独立观测（能分别记录各子权重的范数）
- **MUST**：τ₄（合并）周期 >> τ₁（可塑），否则不稳定
- **SHOULD**：用"资格痕迹×RPE"归一化，防梯度爆炸

# 缺口 2：能量定义

## 2.1 问题本质
P1 提案的"能量感知调度"中，"能量"没定义——是 FLOPs？带宽？焦耳？

## 2.2 实证坐标
- **业界金标准：`J/token`（焦耳每 token）**——"accounts for all energy consumed—from grid input through power distribution, conversion losses, cooling, networking, and GPU computation"。
- 实测参考值（同任务对比）：**Codellama 0.385 J/token / Qwen 0.499 / Deepseek 0.582 / Mistral 0.684**。
- **关键警告**："Efficiency gains do not guarantee lower absolute energy use"——**单次更省 ≠ 总量更省**（Jevons 悖论）。
- 建议报告口径：**Energy per Token** 应成为标准效率指标。

## 2.3 工程方案：**三层能量核算 + 预算转化**

### (A) 定义：三个层次的"能量"
```python
@dataclass
class EnergyCost:
    compute: float      # FLOPs 折算 (可预估算)
    memory: float       # 显存/带宽占用 (bytes·time)
    wall: float         # 实测墙钟能耗 (J, 用 nvidia-smi 功率×时间)
    @property
    def total(self): return alpha*self.compute + beta*self.memory + gamma*self.wall
```
**定义**：**能量 = 加权组合**，权重 α/β/γ 可调（追求不同目标）。

### (B) 单机可测的"能量"（12GB 现实）
**个人机测不了"全链条 J/token"**（没专业功率计），但**可测**：
```python
def measure_energy(fn):
    p0 = nvidia_smi_power()        # 功率(W)
    t0 = time();  out = fn();  t1 = time()
    p1 = nvidia_smi_power()
    return ((p0+p1)/2) * (t1-t0)   # 近似焦耳 (W·s)
```
- **NVIDIA GPU 可直接读功率**（`nvidia-smi --query-gpu=power.draw`）
- 对 4070 Ti，功耗上限 285W，空闲 ~15W → **功耗差反映真实能耗**

### (C) 能量预算转化（把"能量"变成调度信号）
```python
def energy_budget(phase, time_of_day):
    """★关键: 用"能量账本"决定何时做重活"""
    if time_of_day in OFF_PEAK:      # 夜间/用户不用时 → 电费低、可跑重活
        return ENERGY_BUDGET_HIGH    # 允许合并/REM/训练
    else:
        return ENERGY_BUDGET_LOW     # 只做轻量(响应为主)
```
**仿生对应**：**人脑睡眠时清理代谢废物、做巩固**——正是"低能耗时段做重活"。

### 2.4 验收标准
- **MUST**：能读 GPU 实时功率（`nvidia-smi`）
- **MUST**：每次 promote/合并 记录能量成本
- **SHOULD**：统计 `J/有效输出`，纳入可观测性

# 缺口 3：符号接地

## 3.1 问题本质
激活模式如何获得"语义"？为什么某个激活模式"意味着"猫？（Harnad 的经典问题 + Searle 中文屋）

## 3.2 实证坐标（重要！已有实证答案）
- **《Mechanistic Emergence of Symbol Grounding》(2510.13796)**：**接地真的会自发涌现**！关键发现：
  - **接地位于"中层"计算**（middle-layer computations）
  - 机制是 **"aggregate mechanism"**：**注意力头把"环境接地"聚合起来支持语言形式的预测**
  - 验证方法：**环境 token 的存在会降低对应语言 token 的 surprisal**（惊讶度）
- **《The Vector Grounding Problem》**：LLM 的内部状态**可以**是关于世界的——"当内部状态携带关于特定世界条件的信息，并因果地影响语言输出时，这些输出就接地了"
  - **判据**：不是"人类能不能解读"，而是"**输出是否与世界处于正确的关系中**"（即使没有外部解释者）
- **《On measuring grounding》(2512.06205)**：提出**接地剖面(grounding profile)** 五维审计：
  `authenticity`(机制在智能体内部) / `preservation`(原子意义保持) / `faithfulness`(忠实) / `robustness`(抗扰动) / `compositionality`(组合性)
- **《Referential Profiles》(2606.21195)**：区分多种接地：referential / sensorimotor / relational / communicative / epistemic

## 3.3 工程方案：**三管齐下接地**

### (A) 接地机制1：**环境 token 联合训练**（已实证有效）
```python
# 关键: 让"语言符号"与"环境信号"在同一个神经组织里共同激活
sensory_vision.ignite(image)      # 看到猫的图像 → 点亮视觉神经元
sensory_symbol.ignite("猫")       # 同时点亮"猫"符号神经元
# 反复共激活 → 符号神经元与视觉神经元形成束 → 接地
```
**这就是 2510.13796 发现的"aggregate mechanism"**——**环境接地通过注意力头聚合**。
**落地**：多模态输入**同时**喂（不只文本），让符号与环境共激活。

### (B) 接地机制2：**因果验证**（Vector Grounding Problem 的判据）
```python
def is_grounded(symbol_neurons, world_reference) -> bool:
    """判据: 符号的内部状态是否因果地影响输出, 且与世界对应"""
    # 反事实测试: 改变世界 → 符号激活应该变
    act_with = activate(symbol_neurons, world_reference)
    act_without = activate(symbol_neurons, perturbed_reference)
    if distance(act_with, act_without) < GROUNDING_EPS:
        return False        # 符号对世界不敏感 → 没接地
    # 因果测试: 符号激活应该影响下游输出
    out_a = downstream(act_with); out_b = downstream(act_without)
    return distance(out_a, out_b) > CAUSAL_EPS
```
**落地**：把"接地测试"做成**自检作业**（在静默态跑）——**反事实扰动 + 检查符号响应**。

### (C) 接地机制3：**接地剖面审计**（五维自评）
```python
def grounding_profile(system) -> dict:
    return {
        "authenticity":   internal_mechanism_check(system),   # 机制在内部吗
        "preservation":   atomic_meaning_intact(system),      # 原子意义完整吗
        "faithfulness":   output_world_correspondence(system),# 忠实吗
        "robustness":     perturbation_robust(system),        # 抗扰动吗
        "compositionality": compose_test(system),             # 能组合吗
    }
```
**落地**：静默态定期跑"接地审计"，**剖面掉分的符号 → 标记"未接地" → 诚实说不确定**（与 ALG-11 收敛度量联动）。

### (D) 与"自我模型"的联动
- 接地的**元层面**：系统知道自己"哪些符号是接地的、哪些是纯符号操作"
- 这就是**防幻觉的根本机制**：**纯符号组合（没接地）的输出 → 标记为"我不确定"**

## 3.4 验收标准
- **MUST**：多模态输入必须**共激活**（不能只喂文本）
- **MUST**：符号对世界扰动**有响应**（否则未接地）
- **SHOULD**：定期跑接地剖面审计
- **SHOULD**：未接地的符号 → 降低输出置信度

# 四、三个缺口的统一视角

> **它们其实是一个问题的三个面**：
>
> | 缺口 | 本质 | 统一理解 |
> |---|---|---|
> | 时间尺度 | **"什么时候学"** | 快痕迹 × 慢奖励 → 信用分配 |
> | 能量 | **"学要花多少"** | 用能量账本决定"何时做重活" |
> | 符号接地 | **"学的是什么"** | 符号必须与环境共激活、因果对应 |
>
> **三者共同构成"学习的完备定义"：**
> ```
> 学习 = 在正确的时刻(时间尺度) × 用可承受的代价(能量) × 学真正有意义的东西(接地)
> ```
