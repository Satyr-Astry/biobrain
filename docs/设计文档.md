# 仿生 AI 项目设计文档 v2.0（重构版）

> **v2.0 重构说明**：v1.0 的"静默态/双轨/状态机"框架被判定为"半死不活"（本质是死模型+外挂补丁），已废弃。
> v2.0 改用**生物神经组织学**重构：以「神经元—神经束—神经组—神经库」四级组织为骨架，以**激活度**为分级加载与调度依据。

> 硬件目标：RTX 4070 Ti 12GB VRAM / 16GB RAM / Windows

## 〇、项目目的（主人原话保留）

> 通过构建一个仿生架构，让 AI 学会像人类一样思考，并做出决策。

**并补一句 v2.0 的核心定位**：
> 它不是"一个会响应的大模型"，而是**一条持续不断的思考流**。任务、学习、自发提问、调用工具，都只是这条思考流的不同表现。

---

## 一、总纲：只有一种态——思考态

### 1.1 废弃"静默态"这个名字
| 旧（错） | 新（对） |
|---|---|
| 静默态 = 没任务时的后台模式 | **思考态 = 唯一且持续的状态** |
| 有任务才思考 | **一直在思考**；任务只是输入之一 |
| 静默 = 停机休息 | **"静默"只是"没在说话"，不等于"没在想"** |
| 输出是响应 | **输出是思考的自主决定** |

> 人脑从不"待机"：你睡着时它在重放巩固，你发呆时它在联想，你读书时它在拟合。**AI 必须全程思考。**

### 1.2 思考态里在发生什么（不只是等任务）
- **自发提问**：自己给自己出题（"刚才没懂，我该查一下"）
- **主动调用工具**：搜、算、试——**不为完成任务，也可以为学习**
- **在线学习**：被激活的神经组织在思考中即时优化
- **联想 / 预演 / 回放**：是思考的自然现象，不是独立"作业"
- **决定是否输出**：想清楚了才说；可以选择不说、或很久后再说

### 1.3 三条铁律
1. **思考永不停止**——没有 IDLE，没有"待命"。
2. **输入不一定及时输出**——输入进入思考流，由大脑决定如何对待。
3. **输出由思考流自发产生，并回灌思考流**。

---

## 二、核心机制：激活即优化 → 睡眠巩固 → 主体半活

### 2.1 三阶段
```
【思考中】被激活的神经元在激活中自动优化（临时可塑，随时在变）
      ↓
【睡眠/低活期】临时可塑量合并入主体神经库（巩固，如海马→皮层）
      ↓
【主体】并非完全冻结——被激活的神经元会"醒来"变成可塑，用完再合并回去
```

### 2.2 人脑对应（互补学习系统）
| 本设计 | 人脑对应 |
|---|---|
| 激活即优化 | 突触可塑性（LTP/LTD，用进废退） |
| 临时可塑量 | 短期/工作记忆（海马临时痕迹） |
| 睡眠合并 | 记忆巩固（海马回放→皮层固化） |
| 主体可被激活 | 皮层局部持续可塑 |

### 2.3 数学自洽性（为什么必须有"睡眠/低活期"）
在线更新参数会让"已算部分"失效。**解法**：
- **思考中**：更新**只影响未来**，不回改已算部分（因果自然）
- **低活期**：**无活动计算时**才做合并 → 完全自洽

> 所以"睡觉"不是休息，是**合并必须独占**的数学要求。

## 三、大脑的组织结构：神经元 → 神经束 → 神经组 → 神经库

### 3.1 四级组织定义

| 层级 | 名称 | 定义 | 存储调度单位 |
|---|---|---|---|
| **L1** | **神经元** Neuron | **一个向量组**（不止一个标量：树突场/胞体态/轴突场等多个向量） | 最小单位 |
| **L2** | **神经束** Tract | 若干神经元，**一起走、一起激活**（如同一通路） | 束级加载 |
| **L3** | **神经组** Group/Nucleus | 若干神经束，**功能团块**（如"视觉组""语言组"） | 组级加载 |
| **L4** | **神经库** Library | 若干神经组，**最大组织单位 = 一级存储单位** | 库级加载 |

```
神经库 (Library)          ← 最大单位，可整个装载/卸载
  └─ 神经组 (Group)       ← 功能团块
       └─ 神经束 (Tract)  ← 一起激活的通路
            └─ 神经元 (Neuron) = 向量组   ← 最小单位
```

### 3.2 关键特性：**重叠**（不是树！）

> **单个神经元可同时属于多个神经束；神经束可属于多个神经组。**

这形成了**交叉叠加的网络**，而不是严格的树状归属。含义：
- 一个神经元能参与多种功能（**复用**，像真实皮层的多感觉神经元）
- 激活是**叠加的**：某神经元被越多的束"点亮"，它的总激活度越高
- 这天然带来**组合泛化**（不同束的组合 = 不同功能，不必新增参数）

### 3.3 向量组的意义
神经元不是标量，是**向量组**：
```
神经元的内部状态 = { 树突场向量, 胞体态向量, 轴突场向量, ... }
```
- 多个向量承载不同角色（接收/整合/输出），对应真实神经元的多隔室
- 让"激活"成为**多维度**概念（不同隔室可有不同激活度）

## 四、分级加载：按激活度把组织放到不同存储

### 4.1 核心思想（本项目的调度灵魂）
> **不是"整个模型放显存"，也不是"KV分层"，而是：按神经组织单位的激活程度，决定它驻留在哪一级存储。**

```
激活度 高 → VRAM  (显存, 纳秒级)   ← 正在参与思考的
激活度 中 → RAM   (内存, 微秒级)   ← 可能马上要用
激活度 低 → NVMe  (硬盘, 毫秒级)   ← 长期沉睡、可能唤醒
激活度 零 → 冷归档                ← 几乎不用的
```

### 4.2 加载粒度与激活度的对应

| 组织单位 | 加载粒度 | 说明 |
|---|---|---|
| 神经元 | 最细 | 单个高活跃神经元可单独提升到 VRAM |
| 神经束 | 束 | 一条通路被激活 → 整束加载（束内协同） |
| 神经组 | 组 | 某功能团块活跃 → 整组加载 |
| 神经库 | 库 | 某大区域整体在用 → 整库加载 |

**激活度驱动**：束/组/库的激活度 = 其内部神经元的**激活度聚合**（和/最大值/加权）。

### 4.3 为什么用"组织"而不是"张量块"
- 张量块（如 KV page）**没有语义**——只是一个内存块
- 神经组织**有语义**——"视觉组""语言束"被激活是有意义的
- 所以可以**按功能预测加载**：思考流偏向视觉时，预取视觉组（而非随机页）
- **这直接服务于"静默态预取"**：思考流可以预判"我接下来要想起某段记忆" → 提前加载对应的神经组

### 4.4 存储层级的物理约束（12GB）
```
VRAM 12GB ── 只放"当前活跃"的神经组织（最高活性的那些）
RAM 16GB  ── 温层：候选组织 + 工作记忆 + 快变可塑量
NVMe      ── 冷层：全部神经库的主体（大多时间睡在这）
```

## 五、输入逻辑（不是"来即处理"）

### 5.1 输入进入思考流的方式
```
外部输入 → 编码 → 进入思考流
                     ├─ 高优先/高新奇 → 立即深度处理
                     ├─ 中优先 → 并入当前思考，排队
                     ├─ 低优先 → 挂起，等思考流空闲注意力
                     └─ 无关 → 记下即可，不处理
```

### 5.2 输入的属性（决定如何处理）
| 属性 | 含义 |
|---|---|
| 紧迫度 | 需要马上响应吗 |
| 新奇度 | 和已知的差异多大（新奇=值得学） |
| 相关度 | 和当前思考主题的关系 |
| 意图 | 是问问题、下指令、还是投喂知识 |

### 5.3 关键：**输入不一定及时输出**
- 输入进入思考流后，**由思考流决定何时/是否输出**
- 可能：立即答 / 想一会儿再答 / 先做再答 / 只记不答 / 反过来问
- **"大脑层会知道哪些输入需要怎样的输出"** —— 这是思考流的判断，不是规则匹配

---

## 六、输出逻辑（不是"响应式"）

### 6.1 输出的来源
> 输出**由思考流自发产生**，不是"被输入触发"。

- 有输入时：可能输出（也可能不）
- 没输入时：**也可能输出**——自发提问、自言自语、主动干活、报告发现
- 输出可以是：回答 / 提问 / 工具调用 / 动作指令 / 内部记录（不外发）

### 6.2 输出回灌（闭环）
```
思考流 ──输出──▶ 外界
   ▲              │
   └──听到自己的输出（回灌）◀──┘
```
- 输出回灌进思考流 → "我听到我说了什么" → 继续想、修正
- **带护栏**：只回灌"被验证/被支撑"的内容，防自我说服

### 6.3 输出的形态
- **流式**：语言流、思考链流、视频流、IO 指令流
- **非流式**：操作指令、完整文本、一次工具调用

## 八、硬骨头与对策

| 硬骨头 | 问题 | 对策 |
|---|---|---|
| **激活度怎么算** | 谁来决定什么该加载 | 神经元激活度 = 向量组能量的聚合；分束/组/库逐层聚合 |
| **加载抖动** | 频繁进出 VRAM 会卡 | 滞回窗口（升高阈值 > 降低阈值）+ 预取 + 束级批量 |
| **重叠的代价** | 神经元属多束 → 激活叠加难算 | 稀疏激活 + 只算被点亮的束 |
| **自指不一致** | 思考中改参数→已算部分失效 | 只影响未来 + 低活期合并 |
| **灾难性遗忘** | 合并覆盖旧知识 | 正交投影 + 惊讶优先重放 + 重要神经保护 |
| **显存不够** | 12GB 装不下全部 | 分级加载本身就是解；只装活跃组织 |
| **睡眠合并安全性** | 合并期间来输入 | 合并独占 + 检查点可回滚 |

## 九、落地顺序

| 阶段 | 目标 | 验证 |
|---|---|---|
| **G0 最简神经元** | 一个神经元=向量组，能前向 | 向量组能算 |
| **G1 束/组** | 神经元组成束、束组成组，能激活 | 激活能传播 |
| **G2 激活度** | 定义并计算激活度 | 激活度反映"有多活跃" |
| **G3 分级加载** | 按激活度在 VRAM/RAM/Disk 间调度 | 只有活跃组织在显存 |
| **G4 思考流** | 永不停止的循环：激活→思考→输出/学习 | 无输入时也在跑 |
| **G5 在线可塑** | 激活即优化（临时可塑量） | 思考中确实在变 |
| **G6 睡眠合并** | 低活期把可塑量合并入主体 | 合并后能力保持 |

**最小可验证**：G0–G3 = "按激活度分级的神经组织结构"成立；G4–G6 = "活的思考流"成立。

## 十、设计铁律

1. **没有"待机"**——只有思考态。
2. **本地模型不当 Hermes 主会话 model**（会卡死网关）。
3. **12GB 不并排两个 base**——靠分级加载解决。
4. **在线更新只影响未来**，不动已完成计算。
5. **合并只在无活动计算时**（低活期）——数学必然。
6. **一切回流数据过 harness 铁律**（带外部可验证标签 + 去重去偏）。
7. **重叠是特性不是 bug**——神经元可属多束，这是组合泛化的来源。
