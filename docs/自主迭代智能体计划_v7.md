# 自主迭代智能体计划（v7）

> **目标**：让仿生大脑从「实验品」进化为「**能自主迭代的智能体**」
> —— 具备 LLM 级语言能力与接口、能操作浏览器、能上网自学习、能自主规划迭代。
> **约束**：RTX 4070 Ti 12GB / 16GB RAM / Windows / E盘 355GB。
> **原则**：每一步都真跑验证；遇到无法解决的问题或被主人打断才停止。

---

## 三、实施计划

### P1：LLM 级接口（最高优先级）
**目标**：对外表现得像一个标准 LLM。

- [ ] **P1.1** OpenAI 兼容 `POST /v1/chat/completions`
  - 支持 `messages` 数组、`stream`、`temperature`
  - 模型名 `bio-brain`
- [ ] **P1.2** 会话管理（多轮上下文）
- [ ] **P1.3** 神经认知层接入
  - 每轮对话 → 神经组织处理 → 影响回答风格/内容
  - 记忆召回 → 注入上下文
  - 置信度 → 控制回答保守程度
- [ ] **P1.4** 流式输出（SSE）
- [ ] **P1.5** 兼容 OpenAI SDK（用 openai 库能直连）

**验收**：`curl` 和 `openai` Python 库都能正常对话。

### P2：工具层（手脚）
**目标**：能操作浏览器、上网。

- [ ] **P2.1** HTTP 客户端（网页抓取、API 调用）
- [ ] **P2.2** 浏览器控制器
  - 无头/有头模式
  - 打开页面、读 DOM、点击、输入、截图
  - 方案：playwright（若已装）或 CDP 直连
- [ ] **P2.3** 搜索引擎（DuckDuckGo / Bing 免 key，或 Brave API）
- [ ] **P2.4** 工具注册表 + 调用解析
  - LLM 输出 `{"tool": "browse", "args": {...}}` → 执行 → 结果回灌
- [ ] **P2.5** 工具安全护栏（域名白名单、频率限制）

**验收**：让它"查一下今天天气"能真的上网查到。

### P3：网络自学习
**目标**：主动获取知识并固化。

- [ ] **P3.1** 知识提取器（网页 → 结构化文本）
- [ ] **P3.2** 可信度评估（来源分级：官方文档 > 百科 > 论坛）
- [ ] **P3.3** 写入神经记忆（同 `teach`，source 标记为 `web_*`）
- [ ] **P3.4** 去重 + 冲突检测（新知识 vs 旧记忆）
- [ ] **P3.5** 学习日志（学了什么、从哪学的）

**验收**：给它一个主题，它能自己上网学会并记住。

### P4：自主迭代循环
**目标**：无人监督的持续改进。

- [ ] **P4.1** 任务规划器
  - 输入大目标 → 输出步骤列表
  - 用 LLM 做规划（但计划存到神经组织）
- [ ] **P4.2** 执行-验证闭环
  - 每步执行 → 验证结果 → 失败则重规划
- [ ] **P4.3** 进度持久化（中断可恢复）
- [ ] **P4.4** 自我评估（改进是否有效）
- [ ] **P4.5** 迭代日志 + 报告

**验收**：给它一个目标（如"完善项目文档"），它能自己迭代完成。

### P5：安全护栏（贯穿）
- [ ] **P5.1** 循环检测（防死循环）
- [ ] **P5.2** 资源限制（CPU/内存/网络频率）
- [ ] **P5.3** 中断响应（Ctrl+C / 信号）
- [ ] **P5.4** 危险操作确认（删除文件、发消息）
- [ ] **P5.5** 预算上限（最多跑多久/多少轮）

## 五、验收标准

1. **P1**：`openai` SDK 能连上并对话，回答质量接近直连 LLM
2. **P2**：能自主完成"上网查资料 → 总结"的动作
3. **P3**：学到的知识**重启后还在**（持久化）
4. **P4**：给一个目标，能自己跑完并报告
5. **P5**：任何异常都能优雅停止，不失控
