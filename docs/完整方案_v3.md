# 第二部分：神经组织

## 2.1 四级组织
```
神经库 Library   ← 最大单位，一级存储单位
  └ 神经组 Group  ← 功能团块
      └ 神经束 Tract ← 一起激活的通路
          └ 神经元 Neuron = 向量组
```

| 层级 | 定义 | 存储单位 |
|---|---|---|
| 神经元 | **一个向量组**（树突场/胞体态/轴突场） | 最小 |
| 神经束 | 若干神经元，**一起走/一起激活** | 束级 |
| 神经组 | 若干神经束，**功能团块** | 组级 |
| 神经库 | 若干神经组，**最大组织单位** | 库级 |

## 2.2 重叠（核心特性）
> **单个神经元可属于多个神经束；神经束可属于多个神经组。**

含义：神经元被**复用**（像真实皮层的多感觉神经元）；激活是**叠加**的；组合天然泛化（不同束组合=不同功能）。

## 2.3 激活度
```
神经元: activity(n) = σ( w_d·||树突|| + w_s·||胞体|| + w_a·||轴突|| )
束/组/库: activity = aggregate(成员)     # top-k均值, 抗噪
时间衰减: activity(t+1) = decay·activity(t) + 新输入   # 用进废退 (decay≈0.9)
重叠叠加: node.activity_total = base + Σ(活跃束的贡献)
```

# 第三部分：输入与大脑层的连接 ★（主人最关注）

## 3.1 核心答案：输入 = 点亮感觉神经元

> **输入不是"喂进来的数据"，而是"被点亮的感觉神经元组"。**

```
外界信号 ──编码──▶ 感觉神经元组被激活 ──沿神经束扩散──▶ 大脑层
                      ▲
                 (不是"接口调用",是神经组织的自然激活)
```

**连接点 = 感觉神经束的突触**（不是 API/不是张量拼接）。

## 3.2 三类感觉神经元（对应主人的"抽象/具象/流式/非流式"）

| 感觉神经元组 | 负责 | 对应输入 |
|---|---|---|
| **视觉感觉组** | 像素/图像/屏幕采集 → 激活模式 | 具象+流式 |
| **听觉/信号感觉组** | 声音/电压/陀螺仪/传感器 → 激活模式 | 抽象+流式 |
| **符号感觉组** | 文字/指令 → 激活模式 | 具象/抽象+非流式 |

**统一性**：不管哪种输入，最终都变成**"哪些感觉神经元被点亮、多亮"**——这一步统一了所有模态。

## 3.3 输入的完整通路（含编码器=感觉器官）
```
外部信号
   │
   ▼
[编码器 = 感觉器官]  ← 每种模态一个(视觉/听觉/符号), 可即插即卸
   │   把异质信号 → 感觉神经元激活模式
   ▼
[感觉神经束]        ← 固定通路, 负责把信号送进大脑
   │
   ▼
[神经组/库 (大脑层)]  ← 与既有组织汇聚、竞争、扩散
```

**关键**：编码器是"感觉器官"，属于神经系统的**输入端组织**，不是"外挂模块"。

## 3.4 输入的处理逻辑（不是"来即答"）
输入点亮感觉神经元后，**进入思考流参与竞争**：
```
新输入 → 感觉神经元激活 → 激活沿束扩散
                            ↓
              与当前思考主题的既有激活 竞争/汇聚
                            ↓
        思考流根据输入属性判断如何对待:
          · 紧迫度 → 需要立即响应吗
          · 新奇度 → 值得学吗(高新奇=值得学)
          · 相关度 → 与当前思考的关系
          · 意图   → 问问题/下指令/投喂知识
                            ↓
        可能的处理:
          ├─ 立即深度处理 → 快速输出
          ├─ 并入思考流   → 稍后输出
          ├─ 只记录       → 不输出,存为经验
          └─ 挂起         → 等注意力空闲
```

> **"输入不一定及时输出"**——因为输入只是"点亮了一些神经元"，输出与否由思考流的整体状态决定。

# 第四部分：输出与大脑层的连接 ★

## 4.1 核心答案：输出 = 读取运动神经元的激活

> **输出不是"返回的值"，而是"运动神经元组的激活被读出"。**

```
大脑层(思考流) ──激活──▶ 运动神经元组 ──读出──▶ 输出通道 ──▶ 外界
                    ▲
              (不是"函数return",是神经组织的自然激活)
```

**连接点 = 运动神经元组的读出器**（不是 API/不是函数返回）。

## 4.2 输出通道（对应主人的"流式/非流式"）

| 运动神经元组 | 输出 | 类型 |
|---|---|---|
| **语言运动组** | 文字/语言流 | 流式 |
| **思考链运动组** | 思考链流 | 流式 |
| **工具运动组** | 工具调用/IO 指令 | 非流式(离散) |
| **动作运动组** | 电脑操作/机械动作 | 流式/非流式 |
| **媒体运动组** | 图像/视频/音频 | 流式 |

## 4.3 输出的产生（由思考流自发，不是被触发）
```python
def emit_decision(thought_state):
    # 不是"有输入就输出",是思考后的自主判断
    if 思考收敛且路紧迫输入:   return Speak(now=True)
    if 思考未完成:             return Wait()          # 继续想
    if 需外部信息:             return ToolCall(...)   # 调工具
    if 有自发念头:             return Speak(spontaneous=True)
    if 无需外发:               return Internal()      # 只更新内部
```
**无输入也会输出**：自发提问、查资料、练习、报告发现。

## 4.4 回灌（闭环，让思考听到自己）
```
思考流 ──激活运动神经元──▶ 输出
   ▲                        │
   └──点亮"自体感觉神经元"◀──┘   (像听到自己的声音)
            (带 entailment 护栏: 只回灌被推理支撑的内容)
```
- 回灌 = 把输出信号接回**感觉侧**（自体感觉神经元），不是"把字符串塞回输入"。
- 护栏防"自我说服"（前面实证过：无护栏的推理链会把自己说服，ASR 从 2.5%→13%）。

## 4.5 IO 与大脑的连接总图
```
   外界                                          外界
    ▲                                             │
    │                                             ▼
[运动神经组] ◀──读出── [大脑层: 神经组/库] ◀──扩散── [感觉神经组]
   语言/工具/动作                             ▲          视觉/信号/符号
                                              │              ▲
                                        思考流(永不停止)      │
                                              │          [编码器=感觉器官]
                                              ▼              ▲
                                       [自体感觉神经元] ◀──回灌──┘
```

**连接的本质**：IO 不是"接口"，是**神经系统伸出的感觉端和运动端**。

# 第六部分：自训练机制 ★（主人要求写清楚）

## 6.1 核心命题
> **没有"训练阶段"。训练 = 思考的副产品。** 神经组织在每一次激活中被改写；在低活期被巩固；在需要时被合并。

## 6.2 三层自训练机制

```
┌─────────────────────────────────────────────────────────────┐
│ 第一层：在线可塑 (思考中, 毫秒级)                             │
│   被激活的神经元 → 即时微调 (Hebbian / 局部梯度)              │
│   特点: 不回头改已算部分; 只写"临时可塑量"                     │
├─────────────────────────────────────────────────────────────┤
│ 第二层：经验积累 (思考中, 秒~分钟级)                          │
│   把"思考轨迹+结果"存入经验缓冲; 标记"惊讶度"                  │
│   特点: 不是所有都留,按惊讶/价值筛选                          │
├─────────────────────────────────────────────────────────────┤
│ 第三层：睡眠合并 (低活期, 分钟~小时级) ★真正的"训练"          │
│   惊讶样本重放 → 正交投影 → 合并入主体 → 存检查点              │
│   特点: 独占计算; 防遗忘; 可回滚                              │
└─────────────────────────────────────────────────────────────┘
```

## 6.3 第一层：在线可塑（激活即优化）

### 机制
```python
def update_plasticity(active_neurons, state):
    for n in active_neurons:
        if n.activity > PLASTIC_THRESHOLD:      # 只有活跃的可塑
            # Hebbian: 前后共激活 → 增强
            delta = eta * hebbian_term(n, state) - lam * n.plasticity
            n.plasticity += delta               # 只写临时量
```
- `eta` 塑形率、`lam` 衰减率（都可学习）
- **用进则变**：活跃的才改，安静的保持

### 为什么不会"自指不一致"
```
处理序列 t=1..T:
  对每个 t:  前向用 (主体 + 临时可塑量) → 只读
             更新只写 临时可塑量 → 只影响 t+1 起
  所以 1..t 的计算图永不被改 ✅
```

### 学什么
- 神经元的**连接强度**（哪些神经元该一起活跃）
- **信任/权重**（哪些输入可靠）
- **模式**（重复出现的组合 → 固化成束的协同模式）

## 6.4 第二层：经验积累

### 存什么
```python
class Experience:
    thought_trace: list[State]     # 思考轨迹
    inputs: list[Ignition]         # 当时的输入(感觉神经元点亮)
    outputs: list[Emission]        # 当时的输出
    outcome: float                 # 结果好坏(有外部裁判则用裁判)
    surprise: float                # 惊讶度 = |预测 - 实际|
```
### 筛选铁律（防自噬）
- **只留**：带外部可验证标签的（代码跑通了/工具返回正确/用户采纳）→ **优先**
- **只留**：惊讶度高的（偏离预期大 = 最值得学）
- **不留**：自评、重试失败的文本（防 model collapse）
- **去重**：n-gram 重合 / embedding 散度检测

## 6.5 第三层：睡眠合并（真正的"训练"）

### 触发条件
- 全局激活度降到阈值以下（真低活期）
- 或累积可塑量超阈值
- 或显存宽裕

### 完整流程
```python
def sleep_consolidate():
    assert no_active_compute()                   # 必须独占
    
    # ① 惊讶优先重放 (SuRe 式, 仿海马回放)
    samples = select_surprising(experience_buffer, top_k=K)
    for s in samples:
        replay(s)                                # 重跑 → 累积可塑更新 Δ
        accumulate_plasticity(s)
    
    # ② 正交投影 (防灾难性遗忘)
    for n in plastic_neurons:
        # 把新 Δ 投影到"老任务正交补空间"
        n.plasticity = project_orthogonal(n.plasticity, importance=n.fisher)
    
    # ③ 合并入主体
    for n in plastic_neurons:
        n.base_weight = merge(n.base_weight, n.plasticity, mode="reversible")
        n.plasticity.zero_()                     # 清零, 新一轮重新开始
    
    # ④ 4bit 保护 (若量化存放)
    #    冻结 code plane, 只更新 per-block scale (Scale-QLoRA 方案)
    
    # ⑤ 存检查点
    save_checkpoint(rollback_able=True)
```

### 为什么"必须先睡"
- 在线时改参数会毁掉已算部分 → 只能"只影响未来"
- 只有**没有活动计算**时，才能安全地把整段 Δ 折进主体
- **所以睡眠不是休息，是合并的必要条件**

## 6.6 自训练的完整闭环图
```
        思考中                          低活期
   ┌──────────────┐              ┌──────────────────┐
   │ 激活神经元    │              │ 惊讶样本重放       │
   │    ↓         │              │    ↓              │
   │ 在线微调      │──临时可塑量──▶│ 正交投影(防遗忘)   │
   │ (Hebbian)    │              │    ↓              │
   │    ↓         │              │ 合并入主体         │
   │ 产生经验      │──经验缓冲───▶│    ↓              │
   │ (标惊讶度)    │              │ 检查点(可回滚)     │
   └──────────────┘              └──────────────────┘
          ▲                               │
          │         主体变强了             │
          └───────────────────────────────┘
```

## 6.7 防遗忘的四道防线
| 防线 | 作用 |
|---|---|
| 正交投影 | 新知识与旧知识不在同方向叠加 |
| 惊讶优先重放 | 只巩固最有信息量的，不是全部覆盖 |
| 重要神经保护 | Fisher 重要性高的神经不许大改(EWC) |
| 可逆合并 | 出问题能回滚 |

## 6.8 自训练的"学习目标"从哪来（关键！）
自训练不能瞎学，需要**方向**：
| 来源 | 例子 | 可靠性 |
|---|---|---|
| **外部裁判(oracle)** | 代码跑通、数学验证、工具真返回 | ⭐⭐⭐ 最高 |
| **用户真实行为** | 采纳/拒绝/修改 | ⭐⭐ 高 |
| **结果反馈** | 任务成功/失败 | ⭐⭐ 高 |
| **预测误差** | 自己预测 vs 实际 | ⭐ 中（可自监督） |
| 自评 | "我觉得这样更好" | ❌ 不用（防自噬） |

> **铁律**：没有可靠学习信号时，宁可只"在线可塑、不合并"——**不要让不可靠的信号进主体**。

# 第十部分：设计铁律

1. **没有待机**——只有思考态。
