# 第二部分 · JEPA 是什么

## 2.1 核心机制（LeCun 2022 / I-JEPA / V-JEPA）

```
context x ──► Enc_x ──► s_x ──┐
                              ├──► Predictor ──► ŝ_y
target  y ──► Enc_y ──► s_y ──┘                     │
              (EMA, stop-grad)                      ↓
                             loss = D(ŝ_y, s_y)  ← 在【表示空间】比
```

| 组件 | 作用 |
|---|---|
| **context encoder** | 观察信号 → 潜表示 |
| **target encoder** | **EMA 副本**（指数移动平均） |
| **predictor** | 从 context 表示预测 target 表示 |

**两条根本性差异**（vs 生成式）：
1. **在潜空间预测，不在信号空间** —— loss 从不是 `‖ŷ − y‖`
2. **target 是学习得到的** —— `s_y` 来自编码器，不是手工重建目标

**LeCun 的原话**：
> *"Modeling the world for action by generating pixels is as wasteful and doomed to failure as the largely-abandoned idea of 'analysis by synthesis'."*

> *"it **cannot easily be used to predict y from x**. It merely captures the dependencies between x and y **without explicitly generating predictions of y**."*

## 2.2 防坍塌的四代演进

| 代 | 方法 | 机制 |
|---|---|---|
| **I-JEPA / V-JEPA** | EMA + stop-grad + predictor | target 编码器**慢速移动** → 预测器必须追赶 |
| **VICReg** | 方差 + 协方差正则 | 防**维度坍塌**（低秩子空间） |
| **LeJEPA**（arXiv:2511.08544） | **SIGReg** | **证明**最优嵌入分布 = **各向同性高斯** |
| **LeWorldModel**（2026-03） | SIGReg 进世界模型 | **首次从原始像素端到端稳定训练**（~15M 参数） |

## 2.3 LeCun 的六模块蓝图（**JEPA 只占 1 个**）

| 模块 | 作用 |
|---|---|
| configurator | 按任务编排其它模块 |
| perception | 传感器 → 低维世界状态 |
| **world model** | **← JEPA 的家** |
| cost module | 给状态打分（内在/任务目标） |
| actor | 提出动作序列 |
| short-term memory | 保留世界状态 + 代价 |

## 3.1 🔴 区别一：**主人要生成，JEPA 反对生成**

| | JEPA | 主人 |
|---|---|---|
| 输出 | ❌ **无解码器，不生成任何东西** | ✅ **要生成**（矩阵流→反解） |

LeCun 六模块里 JEPA 只占"world model"一个，

## 3.2 🔴 区别二：**"矩阵流"是双向的，JEPA 的潜表示只用于比较**

```
JEPA：   x ──► Enc ──► s_x ──► Pred ──► ŝ_y      （到此为止，不落地）

主人： 传感器 ──► 矩阵流 ──► 神经 ──► 矩阵流 ──► LLM/生图/电压
       ↑ 输入侧                              ↑ 输出侧 ★JEPA没有
```

**★这是实质创新点**：
> JEPA 被生成派攻击的核心弱点：*"JEPA can evaluate a plan; it **cannot hand an agent a new world to practice in**."*
> **如果"矩阵流"能双向翻译，就补上了这个短板。**

## 4.1 ⭐ JEPA 家族的最新演化

### ① Orthogonal JEPA（arXiv:2608.20065）

**问题**（原文）：
> "this monolithic state can allocate redundant capacity to dominant signals while providing weak or conflicting gradients to less dominant predictive structure."

**解法**：**正交预测因子分解**
- 多个**基矩阵** → 把 target 状态分解成多分量
- **每分量一个专属预测分支**
- **正交性目标**（防方向重复）+ **因子活性正则** + **在线方差正则**

**⇒ 用到项目**：KV 缓存/群组**正好是多分量结构** ——
现在所有束共用同一套打分（单体），可改**按因子分解的多分支**

### ② JEPA-Anything（arXiv:2609.20800）

**结论**：同一套 OPF 跨 **7 领域**有效（视觉/生物/临床/控制/分子/物理场/天气）：
- 10 个动力学任务**全部**优于匹配 JEPA 基线
- 干预预测误差 **-34.8%**
- 分子 100 步 rollout **误差最低**

**⇒ 用到项目**：证明"因子分解"**跨模态通用** —— 正好适配主人的多模态矩阵流

### ③ ★★ Akasha 2（arXiv:2601.06212）—— **物理版的主人设想**

| 组件 | 机制 |
|---|---|
| **H-SSD** | **Hamiltonian State Space Duality** —— 隐状态当**相空间点**，哈密顿势下演化 |
| **SMoE-HE** | 稀疏哈密顿专家混合 + **辛积分**（保能量守恒） |
| **HFM** | **Hamiltonian Flow Matching** —— 沿保守场线生成（**比扩散快 4×**） |
| **Holographic Memory** | 分层全息记忆（cell 可递归含子 cell） |

**收益**：能量守恒 · FVD **287**（SOTA）· 比 transformer **3-18×** 加速 · **<50ms** 移动端

**⇒ 用到项目（高度相关）**：
> 主人要"**输出矩阵流 → 电压**" —— **电压是物理量**！
> **哈密顿/辛积分保证能量守恒** → 输出**物理上更可信**（不会输出违反守恒律的电压）

### ④ NCP-ArchPreview（arXiv:2609.10715）

**Next Concept Prediction**：潜空间预测**离散概念**（跨多 token）
- **1.95× 收敛加速**（用 **51.3%** token 匹配 OLMo-3-7B）
- 证明潜空间预测可扩展到**前沿规模**（5.73T tokens）

**⇒ 用到项目**：接 LLM 的接口设计参考

## 4.3 ⭐⭐ 预测编码 / 主动推理（Friston 系）

### 自由能原理（FEP）核心

```
变分自由能 VFE = 意外度(surprise) + KL散度
              = -log p(s|m)  +  D[q(ϑ|h) || p(ϑ|s,m)]

最小化 VFE 两条路：
  (i)  调整内部模型（短期=感知，长期=学习）
  (ii) 通过行动改变世界，使之符合模型（主动推理）
```

**原文**（arXiv:2603.20927）：
> "cognitive processes such as **perception, control, planning, learning, decision-making, attention, habit formation, exploration, and imagination** are no longer treated as separate cognitive faculties, but arise as **consequences of a single inferential principle**."

**⇒ 用到项目（最直接的替代方案）**：
> 主人的**"对齐度判断陌生程度"就是 surprise/预测误差**！
> **不需要反向传播** —— 用 **VFE 最小化**统一：
> - 高对齐（预测准）→ 低 VFE → 不学
> - 低对齐（陌生）→ 高 VFE → 学

### 反应式消息传递（reactive message passing）

**原文**：
> "VFE minimization is naturally realized by **reactive message passing on a factor graph**... **event-driven, interruptible, and locally adaptable**"

**⇒ 用到项目**：正是"**持续传播矩阵流**"的正解 ——
**事件驱动 + 局部并行 + 可中断**（无需全局同步）

### ★★★ SAPIN（arXiv:2511.02241）—— **最像主人设想**

**Structurally Adaptive Predictive Inference Network**：2D 网格上细胞**物理迁移**

| 机制 | 说明 |
|---|---|
| **突触可塑** | 局部 Hebbian —— 基于**实际激活 vs 学习期望的时序差** |
| **结构可塑** | **细胞物理迁移**优化感受野 —— 由**长期平均预测误差**驱动 |

**成果**：解决 Cart Pole 平衡，**无需任何外部奖励/惩罚信号**！

**⇒ 用到项目**：
> **"结构可塑"正是架构书 P-TOPO 缺陷族**！
> SAPIN 给出**具体算法**：神经元按**长期预测误差**迁移/重连
> 项目现在**没有拓扑迁移机制**（只有束的静态归属）

## 4.4 ⭐⭐⭐ 局部学习规则（**替代反向传播**）

### e-prop / E-Prop（Bellec 2020 及后续）

**核心**：把 BPTT 梯度**因式分解成两项**：
```
Δw_ij = Σ_t  L_j(t) · e_ij(t)
              ↑         ↑
       学习信号    资格迹
    （突触后误差）  （前×后活动累积）

三因子规则：前活动 × 后状态 × 调制信号
```

**★ Event-driven E-Prop**（Korcsak-Gorzo et al., 2025-11-26）：
> "triggers updates **strictly on presynaptic spike arrival**... **Only active synapses process information**, reducing computation by **at least an order of magnitude**"

**⇒ 用到项目**：
> **完美符合 NORM-3/NORM-4**！
> - 在线（无需停机训练）
> - 局部（无需全局反向传播）
> - **事件驱动**（正对应主人的"**稀疏发散**"—— 只有活跃路径计算）

### 三因子 + STDP（arXiv:2603.00710）

**关键发现**（消融）：
> "**normalization and reward-shaping settings** as the **strongest observed levers**"
> （归一化 + 奖励塑形是**最强的两个杠杆**）

### ★★★ "资格迹是唯一必需"（researchsquare, 2026）

**最震撼的发现**：
```
消融实验（N=800~80,000 神经元，128M 突触）：
  移除【资格迹】     → 涌现稀疏化归零（ΔGini = -0.006）
  移除其它任何组件   → 保持（99%）甚至放大（310-404%）
```

**原文**：
> "**The eligibility trace is not one contributor among many; it is the sine qua non.**"

**时间尺度定律**（可直接用）：
```
τ_exp ∝ √N

N=80,000 时：τ 从 20,000 → 200,000
              → 差异化均衡 0.365 → 0.584（+60%）
```

**⇒ 用到项目**：
> 1. **资格迹是 P0** —— 项目**完全没有**（`grep` 零命中）
> 2. **τ ∝ √N** 给出**可计算的设计公式**
> 3. 直接支持 **ALG-24**，且**应提升为最高优先级**

### 睡眠 + STDP 稳态（arXiv:2601.08447）★★

**问题**（原文）：STDP 在循环网络三大病理：
> "(i) **weight saturation**... (ii) **representational collapse**... (iii) **catastrophic forgetting**"

**解法**：**突触稳态假说**
```
睡眠期：外部输入抑制 + 突触随机衰减回稳态基线 + 自发活动巩固
```
**效果**：防权重饱和，**保留学到的结构**

**⇒ 用到项目**：项目**已有睡眠**（`Consolidator.nrem/rem`）但曾**从不自动触发** ——
**本次平台实验首次让它自动触发 4 次** ✅
论文给出"睡眠该做什么"的正解：**突触随机衰减回基线**（项目缺！）

## 4.5 前向-前向（Hinton）

**Forward-Forward (FF)**：**两次前向**替代前向+反向
- **正样本**（真实）→ 提高"goodness"
- **负样本**（生成/扰动）→ 降低"goodness"
- **各层独立**，无需全局反向传播

**变体**：Mono-Forward（arXiv:2501.09238）—— 用**局部误差**

**⇒ 用到项目**：如果坚持要"某种反向信号"，FF 是最轻量选项 ——
但 **e-prop 更符合项目的稀疏/事件驱动定位**

# 第五部分 · 三个最重要结论

## 结论 1：**资格迹是必需品**（实证最强）

> **N=80,000 神经元、128M 突触的消融实验证明**：
> - 移除资格迹 → **涌现稀疏化归零**
> - 移除其它任何组件 → **保持或放大**
>
> **⇒ 项目要"涌现稀疏性"，资格迹不是可选项。**

## 结论 2：**"对齐度"有严格数学形式，无需反向传播**

> 主人的"对齐度 → 陌生程度 → 反向调节"
> **= 变分自由能 VFE 最小化**：`VFE = 预测误差 + KL散度`
> - 高对齐 → 低 VFE → 不学
> - 低对齐 → 高 VFE → 学
>
> **⇒ 三因子规则 + 资格迹即可实现，内存 O(1) vs BPTT 的 O(T)**

## 结论 3：**"时空间梯度稀疏发散" = 事件驱动计算**

> e-prop 的 event-driven 实现：
> **只在突触前脉冲到达时更新** → 只活跃突触算 → **计算量降一个数量级**
>
> **⇒ 主人的"稀疏发散"不只是省算力，而是"只有活跃路径参与学习"的严格形式**
