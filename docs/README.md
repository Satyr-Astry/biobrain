# 仿生 AI 项目 · 总索引 (README)

> **项目目标**：构建一个**仿生认知架构**——让 AI 像人脑一样持续思考、在思考中学习、在睡眠中巩固，而不是"先训练后使用"的语言模型。
> **硬件目标**：RTX 4070 Ti 12GB VRAM / 16GB RAM / NVMe / Windows
> **文档总数**：8 份 · **当前有效版本**：`工程规范_v7.3.md`(v7.4) · **代码**：5 个模块 + 32 项测试（含 HTTP 服务）

## 五、规范铁律（NORM）

| ID | 铁律 | 说明 |
|---|---|---|
| **NORM-1** | 无待机 | 只有思考态；主循环永不退出 |
| **NORM-2** | 无接口 | 输入输出是神经组织的感觉端/运动端，非外挂 API |
| **NORM-3** | 无分离 | 训练是思考的副产品，无独立训练阶段 |
| **NORM-4** | 因果优先 | 在线更新只影响未来（pending 缓存提交） |
| **NORM-5** | 合并独占 | 只在无活动计算时（巩固相）合并 |
| **NORM-6** | 可靠信号 | 只让外部可验证信号进主体，自评禁用 |
| **NORM-7** | 资源约束 | 本地模型不当 Hermes 主会话；12GB 不并排两 base |
