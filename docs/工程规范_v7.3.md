# 1. 规范总则

## 1.1 三条不可违反的原则（NORM-1..3）
- **NORM-1 无待机**：系统只有「思考态」。任何"待命/空闲"状态都是违规实现。
- **NORM-2 无接口**：输入输出是**神经组织的感觉端/运动端**，不得实现为外挂 API 调用。
- **NORM-3 无分离**：训练是思考的副产品，不得存在"独立的训练阶段"（低活期合并属于思考态的一部分）。

## 1.2 规范等级
| 标记 | 含义 |
|---|---|
| **MUST** | 必须实现，否则违反架构 |
| **SHOULD** | 应当实现，可因资源受限暂缓（须记录） |
| **MAY** | 可选优化 |
| **PARAM** | 可调参数，须有默认值 |

## 1.3 命名约定
- 组织：`Neuron` / `Tract` / `Group` / `Library`
- 激活：`activity`（标量 [0,1]）
- 可塑：`plasticity`（临时增量）
- 主体：`base`（慢权重，稳定）
- 感觉/运动：`sensory_*` / `motor_*`

# 3. 数据结构规范

## 3.1 Neuron（MUST）
```python
@dataclass
class Neuron:
    id: NeuronID
    # 向量组(多隔室)
    dendrite: Tensor      # [D_DENDRITE]  接收
    soma:     Tensor      # [D_SOMA]      整合
    axon:     Tensor      # [D_AXON]      输出
    base:     VectorGroup # 主体(稳定部分)
    plasticity: VectorGroup  # 临时增量(MUST与base同形)
    # 状态
    activity: float = 0.0
    importance: float = 0.0   # Fisher重要性(防遗忘用)
    # 归属(重叠,MUST用引用集合)
    tract_ids: set[TractID] = field(default_factory=set)
```
**契约**：
- `plasticity` 与 `base` **MUST 同形**（保证可合并）
- `tract_ids` **MUST 是集合**（一个神经元可属多个束）
- `activity` **MUST** 每 tick 先衰减再加新刺激

## 3.2 Tract / Group / Library（MUST）—— v6.0 修订：明确束的双层语义

> **v6.0 修订（修正"束的语义模糊"）**：原版 `Tract.pattern` 语义不明（是成员表还是放电模式？）。修订为**双层语义**：`members`（谁在束里）+ `dynamics`（怎么协同）。

```python
@dataclass
class Tract:
    id: TractID
    # ★v6.0: 双层语义
    members: list[NeuronID]          # 组成: 谁在这个束里
    dynamics: Tensor                 # 动力学: 成员间怎么协同(可学习)
    key: Tensor                      # ★束级路由用的"束标识"(供 ALG-0 阶段B)
    value: Tensor                    # ★束级读出的"束内容"
    activation: float = 0.0
    group_ids: set[GroupID]          # 可属多组(重叠)

@dataclass
class Group:
    id: GroupID
    tract_ids: list[TractID]
    function: str
    activation: float = 0.0
    library_ids: set[LibID]

@dataclass
class Library:
    id: LibID
    group_ids: list[GroupID]
    activation: float = 0.0
    tier: Tier = Tier.NVME
    size_bytes: int
```
**契约（MUST）**：
- `members` 与 `dynamics` **MUST** 分开——前者是"组成"，后者是"协同方式"
- `key`/`value` **MUST** 存在（ALG-0 跨束路由需要）
- 束的激活度定义（MUST）：`tract.activation = aggregate(members) × dynamics_match(...)`——**不只是"成员平均"，还要看协同是否成立**

### ★v6.0 修正：**多路径重复计算**（错误的聚合方式）

> **理论错误**：神经元 n 属束 A、B；A、B 又属组 G。若 `G.activation = agg(A.act, B.act)`，则 **n 的贡献被重复计入 G**——`/sqrt()` 只解决了"束内"，没解决"跨束多路径"。

**修正（MUST）**：**聚合必须在"原子集合"上做，而非在"中间聚合结果"上再聚合**。
```python
def group_activation(g: Group, nervous) -> float:
```

# 4.0 计算内核（ALG-0）—— v6.0 新增 ★★★

> **v6.0 新增（修正"计算定义缺失"）**：v2–v5 讲了组织/调度/可塑，却从未定义"活跃神经元集合上到底算什么"。本节把计算内核钉死——**没有它，方案无法实现**。

## 4.0.1 计算模型总览：**消息传递 + 门控注意力**（双模）

神经元是向量组，其"计算"分两步：**（A）局部消息传递**（束内）+ **（B）全局门控注意力**（跨束）。

```python
def compute(active_set, nervous) -> State:
    """活跃集上的前向计算。复杂度 O(|active|·D + |active|·k·D)"""
    # ── 阶段 A: 束内局部消息传递(沿真实通路, 便宜) ──
    for tract in active_tracts(active_set):
        # 束内神经元互相"打电话", 按束动力学加权
        for n in tract.members:
            msg = sum(tract.dynamics[n,m] * m.axon for m in tract.members if m.active)
            n.soma = activate(n.soma + MSG_GAIN * msg)      # 胞体整合
    # ── 阶段 B: 跨束门控注意力(全局, 稀疏) ──
    # 每个活跃神经元按"束级路由"只看少数相关束(不是全连接!)
    for n in active_set:
        routes = tract_router(n, top_k=ROUTE_K)             # 选 k 个相关束
        for tract in routes:
            w = gate(n, tract)                               # 门控权重
            n.soma += w * aggregate_tract(tract)             # 跨束读入
    # ── 阶段 C: 更新轴突输出(供下游/读出使用) ──
    for n in active_set:
        n.axon = out_proj(n.soma)
    return State({n.id: n.axon for n in active_set})
```

## 4.0.2 三个计算子模块的数学定义

**(A) 束内消息传递（局部）**
```
msg(n) = Σ_{m ∈ tract.members, m≠n} dynamics[n,m] · m.axon
soma(n) += MSG_GAIN · msg(n)
```
- `dynamics[n,m]`：束内协同权重（可学习，即"这个束里 n 和 m 怎么耦合"）
- 复杂度 O(size²)，束小（16–64）所以便宜

**(B) 跨束门控注意力（全局稀疏）**
```
route(n) = top_k( { sim(n.soma, tract.key) | tract ∈ 束索引 } )
w(n, t)  = softmax( sim(n.soma, tract.key) / τ )
soma(n) += Σ_{t ∈ route(n)} w(n,t) · tract.value
```
- **关键：不是 n 和所有神经元全连接，而是 n 先路由到少数"束"**（束作为"粗粒度单元"）
- 复杂度 O(|active| · route_k · D)，与全模型规模解耦
- 这就是"稀疏注意力"在神经组织上的落地：**稀疏单位是"束"，不是"神经元"**

**(C) 胞体激活**
```
soma(n) = activate(soma(n))          # activate = GELU/tanh/LIF 可选
axon(n) = W_out · soma(n)            # 轴突输出
```

## 4.0.3 与前向计算的对接（关键约束）
| 约束 | 说明 |
|---|---|
| **只算活跃集** | 沉默神经元不参与（NORM-1 的性能保证） |
| **复杂度与模型规模解耦** | O(|active|·D + |active|·k·D)，不随总神经元数线性增长 |
| **束是稀疏单位** | 不是神经元对神经元，而是神经元对束（粗粒度） |
| **可兼容 Transformer** | 若把"束"看作 attention head、"dynamics"看作 QK，则与 Transformer 同构 → 可复用预训练 |

**要求(MUST)**：`compute` **MUST** 只遍历活跃集与活跃束，不得全量遍历。
**要求(MUST)**：跨束注意力 **MUST** 走"束级路由"（先选束再细读），不得神经元全连接。
**要求(SHOULD)**：`activate` **SHOULD** 可配置（GELU 兼容 Transformer 预训练 / LIF 兼容脉冲实现）。

## 4.0.4 与 Transformer 的关系（重要的可落地性）
> 本计算模型**不推翻 Transformer**，而是它的一般化：
> - 若 1 束 = 1 个 attention head，dynamics = QK 权重，路由 = 稀疏 attention → **退化为稀疏 Transformer**
> - 因此**可以"从预训练 Transformer 热启动"**：把 Q/K/V 权重初始化到 dynamics/out_proj，再扩成多束结构
>
> **这解决了"从零训练太贵"的工程现实**。

# 4.1 激活度计算（ALG-1）—— v4.1 修订：增加"新增激活"与稀疏更新

> **v4.1 修订**：原版只有衰减没有新增激活（神经元会全部熄火=死机），且全量遍历不可扩展。修订为**稀疏活跃集**模型。

```python
# 神经元激活度(向量组能量)
def neuron_energy(n: Neuron, w: Weights) -> float:
    return w.d*norm(n.dendrite) + w.s*norm(n.soma) + w.a*norm(n.axon)

# 逐级聚合(自底向上)
def aggregate(items, k=TOP_K_AGG) -> float:
    return mean(top_k([i.activity for i in items], k))

# ★新增: 激活写入(刺激/扩散的唯一入口)
def ignite(n: Neuron, amount: float):
    n.activity = clamp(n.activity + amount, 0.0, 1.0)   # MUST 归一化到[0,1]

# ★新增: 稀疏 tick (只处理活跃集, 不遍历全部)
def tick_activation(nervous, active_set):
    # 1. 先衰减(只衰减活跃集及其邻域)
    for n in active_set:
        n.activity *= DECAY
    # 2. 再加新增激活(输入/扩散/自发放电)
    for src, amount in nervous.pending_ignitions:
        for n in neighbors(src):          # 只波及邻域
            ignite(n, amount * synaptic_gain(src, n))
    # ★v7.1: 3. 束内扩散(代码验证暴露的缺失环节 —— 无此则神经元全熄火)
    spread = {}
    for n in active_set:
        for tract in n.tracts:
            for m in tract.members:       # 活跃神经元的激活传给束内同伴
                spread[m] += n.activity * abs(tract.dynamics[n,m]) * SPREAD_GAIN
    # ★v7.1: 4. 跨束桥接(架构级补充 —— 无此则激活传不到远处组织)
    for t1 in active_tracts:
        for t2 in all_tracts:             # 束激活经 key 相似度桥接到其他束
            sim = cosine(t1.key, t2.key)
            if sim > BRIDGE_SIM:
                for m in t2.members:
                    spread[m] += t1.activation * sim * BRIDGE_GAIN
    for m, amt in spread.items():
        ignite(m, min(amt, SPREAD_CAP))   # 扩散 MUST 有上限(防爆)
    # 5. 活跃集重估(低于阈值的移出)
    active_set = {n for n in active_set if n.activity > ACTIVE_EPS}

```

> **★v7.1 重要注记（C5）**：**信号传播需要时间**——实测中运动区激活从 5 步的 0.02 爬到 15 步的 0.91。这**不是缺陷，是仿生特性**（人脑突触传导、轴突传导都有延迟）。**正因如此，思考流"永不停止"不是修辞，而是架构必需**：必须持续 tick，信号才能传遍组织。
| 项 | 复杂度 | 说明 |
|---|---|---|
| 神经元能量 | O(|active| · D) | **只算活跃集**，非全量 |
| 稀疏 tick | O(Σ |邻域|) | 稀疏: 只波及被激活的邻域 |
| 逐级聚合 | O(Σ 成员数) | 束→组→库 |
| **总计** | O(|active|·D + Σ邻域) | **与全模型规模解耦** |

**要求(MUST)**：激活写入 **MUST** 经 `ignite()`（唯一入口），保证归一化到 [0,1]。
**要求(MUST)**：tick **MUST** 用**稀疏活跃集**，不得全量遍历（否则违反 NORM-1）。
**要求(MUST)**：聚合 **MUST** 用 top-k 均值（抗单点噪声），不得用 sum。

## 4.2 重叠叠加（ALG-2）—— v4.1 修订：定义 contribution + 归一化防爆炸

> **v4.1 修订**：原版 `contribution()` 未定义；且重叠逐级叠加会让激活度无界增长（激活爆炸）。

```python
    # 该神经元在束内的"协同权重" × 束激活度
    return tract.pattern[node.id] * tract.activation

# ★修订: 带归一化的重叠叠加(防爆炸)
def total_activity(node, nervous, eps=ACTIVE_EPS):
    base = node.activity
    extra = 0.0
    n_tracts = 0
    for tid in node.tract_ids:                    # 稀疏: 只遍历已点亮的束
        t = nervous.tracts[tid]
        if t.activation > eps:
            extra += contribution(t, node)
            n_tracts += 1
    # MUST 归一化: 参与束越多, 单束影响被摊薄, 防止多归属导致爆表

    return clamp(base + extra, 0.0, 1.0)
```
**复杂度**：O(平均束数)，稀疏后接近 O(1)。

## 4.3 在线可塑（ALG-3）—— v6.0 修订：**解决时序悖论（写缓存 + 下步生效）**

> **v6.0 修订（解决时序悖论）**：原版 `hebb = eta*outer(pre, post)` 要求"当前 state 的 post"，但更新又必须"当前 token 生效前完成"——**逻辑冲突**。v6.0 采用**延迟可塑**：用 t-1 的 post 计算、写入缓存、t 步生效，严格因果且无循环依赖。

```python
def update_plasticity(active_neurons, state_t, state_prev):
    """v6.0: 用 t-1 的 post 算更新, 缓存后 t+1 生效 —— 严格因果"""
    for n in active_neurons:
        if n.activity < PLASTIC_THRESHOLD: continue      # 用进则变
        pre  = n.dendrite_proj(state_prev)   # ★用上一步的输入投影
        post = n.axon_proj(state_prev)       # ★用上一步的输出响应(t-1)
        hebb = eta * outer(pre, post)        # 维度对齐 D_PLASTIC
        delta = hebb - lam * n.plasticity
        n.plasticity_pending = clip_norm(n.plasticity + delta, NORM_CLIP)  # ★写缓存
        n.importance = (1-FISHER_DECAY)*n.importance + FISHER_DECAY*norm(hebb)

def apply_pending_plasticity(active_neurons):
    """★在下一步开始前提交, 保证"更新只影响未来" """
    for n in active_neurons:
        if n.plasticity_pending is not None:
            n.plasticity = n.plasticity_pending
            n.plasticity_pending = None
```
**时序保证（MUST）**：
```
t 步: 前向(用 plasticity[t]) → 计算 delta → 写入 plasticity_pending
t+1步: 先 apply_pending → 前向(用 plasticity[t+1])
```
| 方案 | 因果性 | 滞后 | 采用 |
|---|---|---|---|
| 用 t 的 post 立即更新 | ❌ 破坏已算部分 | 无 | 否 |
| **用 t-1 的 post + 缓存** | ✅ 严格 | 1 步 | **是** |
| 同刻可塑但 t+1 生效 | ✅ 严格 | 1 步 | 等价备选 |

**复杂度**：O(A · D_PLASTIC²)。
**要求(MUST)**：`plasticity` 与 `base` **同形**（用低秩形状，如 [r,d]）。
**要求(MUST)**：**更新 MUST NOT 影响当前步已算部分**——必须经 `pending` 缓存、下一步提交。
**要求(MUST)**：`importance` **MUST** 在线累积（ALG-7 正交投影的依据）。

```
  ├─ 巩固相 (CONSOLIDATE): NREM/REM                    ← 无"活动计算"(独占)
  └─ 休眠相 (QUIESCENT):  极低功耗的监测(只收输入, 不算)

```

**语义定义（MUST）**：
| 概念 | 定义 |
|---|---|
| **"思考不停"** | 主循环持续运行、持续接收输入、持续演化状态 |
| **"活动计算"** | **特指"计算相"内的前向与可塑** |
| 合并独占 | 仅在**巩固相**执行，此时"活动计算"为假 |

**要求(MUST)**：实现 **MUST** 用"相(phase)"组织循环，**MUST NOT** 用"启动/停止循环"来切换。
**要求(MUST)**：`can_consolidate()` 判断的是**是否有未完成的"计算相"任务**，而非"循环是否在运行"。

## 4.6 激活预算控制器（ALG-10）—— v5.0 新增

> **v5.0 新增（P0-2，吸收 2026 "逆向缩放"教训）**：热点实证表明"想得越多越好"是错的——**思考 token 超过临界点后质量反而下降**（inverse scaling），收益平台化。生产教训是 **"adaptive compute, spend per input, not maximal compute"**。本项目由此引入**激活预算**：不是激活越多越好，而是按需分配。

```python
def spread(nervous, topic, budget: float):
    """★v5.0: 激活扩散受预算约束, 超预算即截断"""
    total_sent = 0.0
    frontier = seed_neurons(topic)
    while frontier and total_sent < budget:
        n = frontier.pop_max_activity()
        amount = n.activity * SPREAD_GAIN
        if total_sent + amount > budget:
            amount = budget - total_sent          # MUST 截断, 不超支
        for m in neighbors(n):
            ignite(m, amount * synaptic_gain(n, m))
            frontier.push(m)
        total_sent += amount
    # 预算耗尽 → 停止扩散(宁可留着, 不可爆表)

def estimate_budget(task, history) -> float:
    """★自适应预算: 难任务多给, 易任务少给, 失败率高则收紧"""
    difficulty = estimate_difficulty(task)        # 由历史相似任务的成功率估
    base = BUDGET_BASE
    b = base * (1 + difficulty_scale * difficulty)
    if recent_failure_rate(history) > FAIL_RATE_HIGH:
        b *= BUDGET_SHRINK_FACTOR                 # 最近老失败 → 收紧, 防越陷越深
    return clamp(b, BUDGET_MIN, BUDGET_MAX)
```

## 4.7 收敛度量（ALG-11）—— v6.0 新增 ★

> **v6.0 新增（修正"缺收敛度量"缺口）**：思考永不停止，但**何时该输出**？原版只说"自主判断"，没给标准。本节定义收敛度量——**没有它，思考是永动机，永远不知道停**。

```python
def convergence(state_hist, goal) -> float:
    """收敛度 [0,1]: 越高越"想清楚了" """
    # 三因子
    stability = 1 - var(recent_states(state_hist, window=W))   # 激活模式稳定性
    pred_err  = 1 - normalize(prediction_error(state_hist))     # 预测误差下降
    goal_hit  = goal_satisfaction(state_hist, goal)             # 目标达成度
    return w1*stability + w2*pred_err + w3*goal_hit             # 可学习权重

def emit_decision(state, state_hist, goal, inputs):
    c = convergence(state_hist, goal)
    if c > CONVERGE_HIGH:                 # 想清楚了
        return Speak(now=True) if inputs else Speak(spontaneous=True)
    if c < CONVERGE_LOW and elapsed() > PATIENCE:   # 想不出来
        return Speak(content="我不确定/我需要更多信息")  # ★诚实,防幻觉
    if need_external():  return ToolCall(...)
    if no_goal():        return Internal()          # 继续想
    return Wait()                                   # 继续收敛
```
**收敛三因子（MUST）**：
| 因子 | 含义 | 作用 |
|---|---|---|
| **稳定性** | 激活模式是否不再剧烈变化 | 想法定了 |
| **预测误差** | 是否不再有"意外" | 理解到位了 |
| **目标达成** | 是否满足任务目标 | 目的达到了 |

**要求(MUST)**：`emit_decision` **MUST** 基于收敛度量，不得纯随机/纯固定步数。

## 4.8 多尺度权重（ALG-12）—— v7.0 新增（解决"时间尺度耦合"）

> **v7.0 新增**：本方案有 5 个时间尺度（毫秒可塑/秒级衰减/分钟合并/天级神经发生），原版未说清耦合。**NeurIPS《Learning at Multiple Timescales》定理**给出解法：**"假设尺度耦合的模型可通过重参数化消除耦合，等价于多尺度学习器"**——即不需要显式建模耦合。

```python
@dataclass
class MultiScaleWeight:
    subweights: list[Tensor]   # [w_fast, w_mid, w_slow] 独立学习
    etas:   list[float]        # [0.1, 0.02, 0.001]
    decays: list[float]        # [0.5, 0.9, 0.999]
    def value(self): return sum(self.subweights)   # 有效权重 = 求和

def learn_multiscale(w: MultiScaleWeight, e_trace, reward, expected):
    """三因子可塑性: 资格痕迹(快) × 奖励预测误差(慢)"""
    rpe = reward - expected                    # 慢信号: 事后才知道好坏
    for i, (sub, eta, lam) in enumerate(zip(w.subweights, w.etas, w.decays)):
        e_i = lam * e_trace[i] + hebbian_term()     # 快: 资格痕迹
        sub += eta * e_i * rpe                      # ★耦合发生在这里
        e_trace[i] = e_i
```
**尺度参数（MUST）**：
| 子权重 | 学习率 | 衰减 | 作用 |
|---|---|---|---|
| w_fast | 0.1 | 0.5 | 快速适应（当前任务） |
| w_mid | 0.02 | 0.9 | 中期记忆（本次会话） |
| w_slow | 0.001 | 0.999 | 长期知识（合并进 base） |

**要求(MUST)**：权重 **MUST** 表示为**多子权重之和**（不显式建模尺度耦合）。
**要求(MUST)**：**τ(合并) MUST >> τ(可塑)**，否则不稳定。
**要求(MUST)**：信用分配 **MUST** 用"资格痕迹 × 奖励预测误差"（三因子）。
**要求(SHOULD)**：各尺度的范数应可观测。

# 9. 鲁棒性设计

## 9.1 数值稳定
- **MUST**：所有范数计算前做 clip；sigmoid 用数值稳定实现
- **MUST**：`plasticity` 有范数上限（`NORM_CLIP`）
- **SHOULD**：混合精度时关键累加用 fp32

## 9.2 调度稳定（防抖动）
- **MUST**：滞回阈值（升≠降）
- **SHOULD**：降级有冷却时间（同一库 N 秒内不反复升降）
- **SHOULD**：批量搬运（束级，非单个神经元）

## 9.3 学习稳定（防退化）
- **MUST**：可靠信号过滤（防自噬）
- **MUST**：合并可逆（可回滚）
- **SHOULD**：多样性检测（embedding 散度跌破阈值告警）
- **SHOULD**：正交投影防覆盖

## 9.4 容错
| 故障 | 处理 |
|---|---|
| 编码器失效 | 该模态降级，不影响其他 |
| 预取失败 | 忽略，按需加载 |
| 合并失败 | 回滚检查点，保留 plasticity |
| 显存不足 | 降级最低激活库；仍不足则限流 |
| 单神经元异常值 | clip + 告警 |

## 9.5 可观测性（MUST）
- 每 tick 记录：全局激活分布、VRAM 占用、搬运次数、可塑量范数
- 告警阈值：搬运次数/秒过高（抖动）、可塑量爆炸、激活度全零（死机）

# 10. 故障处理与降级

## 10.1 降级等级
```
L0 正常: 全功能
L1 资源紧张: 关闭预取, 降低束/组粒度
L2 显存危险: 只保活跃组, 冻结非必要
L3 保护: 停止在线可塑, 只做前向(保命)
L4 只读: 停止一切写入, 等待人工
```

## 10.2 恢复
- 从检查点恢复主体
- plasticity 未合并的可丢弃（不损主体）
- 经验缓冲持久化，可延后合并

## 11.1 单元测试（MUST）

| 自训练闭环 | 在线可塑可见 + 低活期合并成功 |
